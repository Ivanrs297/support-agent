# Labs

One hands-on lab per lecture, nine in total. Each one is added together with its
lecture slides, and follows the same shape:

```
lN/
├── README.md     # goal, acceptance criteria, known traps, deliverable
├── starter/      # skeleton with TODOs
└── solution/     # reference implementation
```

Labs run against the host provisioned in the module and the agent in
[`project/`](../project/) — not against a toy environment.
